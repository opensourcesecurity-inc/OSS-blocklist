# OSS Curated Blocklist

**Maintained by [Open Source Security, Inc.](https://opensourcesecurity.net)**

Enterprise-grade IP threat intelligence for home and small business networks.

---

## Sources

- **Spamhaus DROP** - Hijacked networks and spam operations
- **Hagezi Threat Intelligence** - Comprehensive threat feeds
- **DShield Top 20** - Most active attacking IPs
- **OSS Community Reports** - Customer-reported malicious sites

Customer-reported threats are verified, added to this blocklist, and shared upstream with the original maintainers.
